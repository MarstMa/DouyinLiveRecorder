# 开发执行步骤（路线图）

> 状态：⬜ 未开始 / 🔄 进行中 / ✅ 已完成

| 阶段 | 内容 | 状态 |
|---|---|---|
| 0 | 工程骨架 + 标准文档 | ✅ 已完成 |
| 1 | 开播检测（先证明能检测到开播） | ✅ 已完成（已实测通过） |
| 2 | 录制（证明能录出文件） | 🔄 代码完成，待真实直播实测 |

## 阶段 0：工程骨架 + 标准文档
- **做什么**：建 `docs/`、`开发日志/` 文件夹；写 `CLAUDE.md`；写三份标准文档；初始化 git。
- **验收**：三份标准文件内容完整；CLAUDE.md 路径正确。

## 阶段 1：开播检测
- **做什么**：搭 Python 环境；写 `app/config.py`、`app/extractor.py`（streamget 封装 + 抖音号转换）、`app/detector.py`（轮询线程）。
- **验收**：命令行对任意直播间链接打印出「是否开播 / 主播名 / 标题 / 画质」。

## 阶段 2：录制
- **做什么**：写 `app/recorder.py`（ffmpeg 录 .ts → remux .mp4，H.265 转 H.264）。
- **验收**：开播期间启动录制，下播后生成 .mp4，可播放、只有主播声音。

## 阶段 3：图形界面
- **做什么**：PySide6 主窗口 + 淡蓝 QSS + 主播列表 + 添加/编辑对话框 + 设置对话框。
- **验收**：能通过界面添加主播、看到状态、设置文件夹和画质。

## 阶段 4：调度 + 后台 + 自启
- **做什么**：`app/scheduler.py`（单录策略 + 弹选）、系统托盘 + 最小化、`app/autostart.py`（自启）。
- **验收**：多主播单录、同时开播弹选、托盘常驻、自启正常。

## 阶段 5：打包
- **做什么**：PyInstaller 配置（打包 ffmpeg.exe、图标、单文件 exe）。
- **验收**：干净环境双击运行正常。

## 阶段 6：录屏备用模式（次要）
- **做什么**：Playwright 隐藏浏览器 + ffmpeg gdigrab，作为截流失效兜底。
- **验收**：手动触发录屏能录出画面。
