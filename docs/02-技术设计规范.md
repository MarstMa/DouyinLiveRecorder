# 技术设计规范

## 1. 技术栈

| 项 | 选择 | 说明 |
|---|---|---|
| 语言 | Python 3.12 | 打包成 exe 后用户无需装环境 |
| 界面 | PySide6（Qt） | 原生窗口、系统托盘、QSS 做深色主题 |
| 抓流 | `streamget` 库（ihmily 开源） | 返回 m3u8/flv 地址、开播状态、主播名、画质 |
| 录制 | ffmpeg（随软件打包） | 直录直播流，纯声音、省资源、后台运行 |
| 打包 | PyInstaller | 单个 .exe，双击即用 |

## 3. 模块职责

- `config.py`：配置读写（JSON），主播列表 CRUD，默认值。
- `extractor.py`：`streamget` 封装 + 抖音号→直播间链接转换 + Cookie；对外统一接口，抓流逻辑**独立成易替换模块**。
- `recorder.py`：ffmpeg 录制 `.ts` → 下播 remux `.mp4`，H.265 自动转 H.264。
- `scheduler.py`：后台轮询检测 + 多主播同时录制（每个开启自动录制且开播的主播各录各的）。
- `autostart.py`：注册表 Run 键实现开机自启。
- `avatar.py`：下载抖音头像到本地缓存。
- `video_library.py`：扫描已录视频，按主播分组；`scan_streamer_videos` 取单主播视频。
- `ui/main_window.py`：窗口外壳（顶部横幅）+ 托盘。
- `ui/streamer_page.py`：三级导航（列表 → 主播页 → 编辑页）+ 折叠日志。
- `ui/settings_dialog.py`：设置对话框；`ui/theme.py`：深色 QSS 主题。

## 6. ffmpeg 录制参数规范

录制 `.ts`（中断更安全）：
```
ffmpeg -rw_timeout 30000000
  -protocol_whitelist "rtmp,crypto,file,http,https,tcp,tls,udp,rtp"
  -thread_queue_size 1024
  -analyzeduration 20000000 -probesize 10000000
  -fflags +discardcorrupt
  -i <stream_url>
  -c:v copy -c:a aac
  -reconnect_delay_max 60 -reconnect_streamed -reconnect_at_eof
  -f mpegts output.ts
```
下播后封装为 `.mp4`：`ffmpeg -i output.ts -c copy output.mp4`（H.265 时转 H.264：`-c:v libx264 -c:a aac`）。

## 8. 文件命名规范

- 视频：`主播名_YYYYMMDD_HHMMSS.mp4`

## 9. 代码规范

- 面向对象、模块解耦；抓流逻辑独立成易替换模块。
- 注释用中文，关键逻辑加说明。
- 网络请求失败要重试和降级（截流失效时提示可切换录屏）。
