# 需求说明

## 1. 项目目标

一个运行在 Windows 11 上的直播录制软件：自动检测抖音主播是否开播，开播自动录制，下播自动生成视频保存到自定义文件夹。后台运行不打扰正常使用，只录主播声音。图形界面直观易懂，淡蓝色主题。

## 2. 核心流程

检测开播 → 自动开始录制 → 检测下播 → 自动停止并生成视频文件 → 保存到自定义文件夹（文件名含主播名 + 日期时间）。

## 3. 功能需求

### 3.1 主播管理
- 支持添加多个主播。
- 添加方式：粘贴直播间链接 或 输入抖音号（两者都支持，自动识别）。
- 可自定义：主播名、保存文件夹、画质、录制方式。
- 支持启用/停用、编辑、删除主播。

### 3.2 开播检测
- 后台自动轮询各主播的开播状态。
- 检测间隔可配置（默认 20 秒）。

### 3.3 录制
- 录制方式：**截流**（抓直播源，优先完善）和**录屏**（备选），做成可选项。
- 同一时间可录制多个主播，各自独立录制、互不影响。
- 每个开启自动录制且正在直播的主播，都会自动开始录制。
- 画质可选：原画 / 超清 / 高清 / 标清 / 流畅。

### 3.4 自动保存
- 下播后自动生成视频（.mp4），保存到自定义文件夹。
- 文件名：`主播名_日期_时间.mp4`。

### 3.5 运行形态
- 后台常驻：关闭窗口后仍在系统托盘运行。
- 可开机自启。

## 4. 非功能需求
- 后台运行，不打扰正常使用电脑。
- 只录主播声音，不录其他软件声音。
- 运行于 Windows 11。
- 最终交付双击即用的 .exe，无需安装 Python。

## 5. 界面需求
- 图形界面，直观易懂（面向不懂代码的用户）。
- 主色调：淡蓝色。

## 6. 决策记录（2026-09-16 与用户确认）

- 录制方式：截流优先完善，录屏作为备选，两者都做成用户可选项。
- 主播数量：多个，同一时间可同时录制（后改为多主播各自独立录制）。
- 多主播同时开播：各自独立自动录制，无需手动选择。
- 画质：做成可选项。
- 登录：先按公开直播处理，需要登录时再加 Cookie 支持。
- 运行形态：后台常驻（托盘）+ 可开机自启。
- 开发方式：小步、安全、可追溯 —— 分阶段推进，每阶段停下给用户确认。
