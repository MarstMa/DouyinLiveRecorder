# 抖音直播录制软件

一款运行在 **Windows 11** 上的抖音直播录制工具。自动检测主播是否开播，开播自动录制、下播自动保存，全程后台运行、不打扰正常使用。

> 版本 0.2 · 作者 MarstMa

## 功能特性

- 🔍 **自动检测开播**：定时扫描主播开播状态，主播一开播就自动开始录制。
- 🎬 **自动录制**：截流录制主播原始画面（可自定义画质：原画 / 超清 / 高清 / 标清 / 流畅）。
- 💾 **自动保存**：主播下播后自动收尾并保存为 mp4 文件。
- 🔔 **Windows 通知**：开播、录制开始、录制结束、抖音风控，都会在右下角弹通知提醒。
- 👤 **多主播同时录制**：可添加多个主播，互不干扰，同时录制。
- 🖼️ **头像识别**：通过抖音号自动抓取主播头像。
- ⏰ **热门开播时段**：每个主播可单独设置热门时段，时段内检测更频繁。
- 🎨 **现代深色主题**：卡片式三级界面，直观易用。
- 🚀 **开机自启、后台常驻**：可最小化到系统托盘继续运行。
- 🔄 **自动检查更新**：启动时自动检查新版，有新版本弹窗提醒、一键跳转下载。

## 环境要求

- **Windows 11**
- **Python 3.12**（[官网下载](https://www.python.org/downloads/)）
- **FFmpeg**（录制必需，见下方说明）

## 安装步骤

1. 安装 Python 3.12（安装时勾选 *Add Python to PATH*）。
2. 安装依赖：

   ```powershell
   pip install -r requirements.txt
   ```

3. 下载 FFmpeg：
   - 从 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载 `ffmpeg-release-essentials.zip`；
   - 解压后，把 `bin` 文件夹里的 `ffmpeg.exe` 和 `ffprobe.exe` 两个文件，
     放进本项目的 `assets` 文件夹里（这两个文件较大，未随代码提交）。

## 运行

```powershell
python main.py
```

首次运行后，点右上角「设置」可调整检测间隔、默认画质、开机自启等；在主播页点「添加主播」即可开始使用。

## 目录结构

```
├── main.py               # 程序入口
├── app/                  # 源码
│   ├── config.py         # 配置读写
│   ├── extractor.py      # 开播状态 / 头像抓取（易替换模块）
│   ├── recorder.py       # FFmpeg 录制
│   ├── scheduler.py      # 后台检测调度
│   └── ui/               # 界面
├── assets/               # 放置 ffmpeg.exe / ffprobe.exe（需自行下载）
├── docs/                 # 需求、设计、开发步骤文档
└── 开发日志/              # 每日开发日志
```

## 说明

- 本工具仅用于个人学习与记录自己喜欢的主播直播内容，请勿用于商业用途或侵犯他人权益。
- 抖音的接口可能随版本更新而变化，抓流逻辑集中在 `app/extractor.py`，便于后续维护替换。
- 配置与录制文件保存在用户目录下（`%APPDATA%\StreamerRecording\`），不随代码提交。
